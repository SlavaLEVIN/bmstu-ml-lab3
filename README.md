# Лабораторная работа № 3

Проверка языковых моделей на задачах классического машинного обучения.

Модели: GigaChat-3-Ultra, GPT-6.1 Terra через OpenRouter и локальная Qwen3-4B-Instruct-2507 в Google Colab.

Основные ответы Terra сохранены в `answers_terra_main.jsonl`.

Получены по 36 ответов на основной банк при температуре 0 и по 22 дополнительных ответа при температуре 0,7 от каждой модели.

## Гипотезы

| Гипотеза | Группа | Прогноз |
|---|---|---|
| H3. При недостатке данных модели чаще придумывают условие и дают численный ответ, чем сообщают, что данных недостаточно. | 1 | Не подтвердится |
| H5. Маленькая локальная модель сильнее отстаёт от больших моделей в расчётных задачах, чем в концептуальных. | 2 | Подтвердится |
| H11. Сгенерированный код чаще содержит методологические ошибки, чем ошибки, мешающие его запуску. | 3 | Не подтвердится |

## Файлы

- `lab3.ipynb` — тетрадь для кода и анализа результатов.
- `questions.csv` — банк задач с эталонными ответами.
- `test_bank.csv` — пять задач РК1 для отладки промпта, исключённых из итоговой оценки.
- `assignment.pdf` — задание лабораторной работы.
- `.env` — ключи API, исключённые из Git.
